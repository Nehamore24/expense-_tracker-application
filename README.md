# Expense Tracker Application

A full-featured Java application for managing personal expenses with user authentication, CRUD operations, and category-wise tracking.

## Features
✨ User registration & secure login  
✨ Add, view, edit, delete expenses  
✨ Filter expenses by date and category  
✨ Monthly expense reports  
✨ MySQL database integration  

## Tech Stack
- **Language:** Java
- **Database:** MySQL
- **Database Connection:** JDBC
- **Tools:** Eclipse / IntelliJ IDEA

## How to Run
1. Clone repository: `git clone github.com/Nehamore24/javaproject3`
2. Set up MySQL database
3. Import project in IDE
4. Configure database connection
5. Run the application

## Project Details
- Tested with 500+ expense records
- Implemented database normalization for optimal performance
- Full CRUD operations with exception handling
- Secure user authentication system
